# Ilia Thunder Studio

Professional bilingual portfolio for games, websites, apps, tools, and experiments by Ilia Rasani.

## What is included

- English and Persian modes with full RTL support
- Always-visible language switch labeled in both languages
- Product categories, search, cards, detailed product dialog, screenshot gallery, and action buttons
- Responsive mobile, tablet, and desktop design
- Accessible keyboard controls and reduced-motion support
- No framework, package install, database, or paid service
- Automatic GitHub Pages deployment

## Publish

Upload every file and folder in this repository to the `main` branch of your GitHub repository.
Then open **Settings → Pages** and select **GitHub Actions** as the source once. Future file uploads
publish automatically.

For exact product instructions in Persian and English, read [ADDING_PRODUCTS.md](ADDING_PRODUCTS.md).

## Quick edits

- Add or edit products: `products.js`
- Add contact links: `site-config.js`
- Upload product media: `assets/products/YOUR-PRODUCT/`
- Change site wording: translation text in `script.js`
- Change colors and layout: `styles.css`

This is a static site. Visitors cannot upload or edit products. Only GitHub repository collaborators
with write access can change its content.
